# 资料收藏夹

本文件夹存放项目相关的参考资料、截图、教程、灵感素材等。

## 使用规则

- 所有外部资料统一放这里，命名格式：`序号-简短描述.扩展名`
- 新增资料后，在下方"资料清单"中补充一行说明
- 图片直接放本目录，文档可建子目录分类
