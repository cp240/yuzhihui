# 语文智学 — 产品方案 v2.0

> 核心定位：孩子只做两件事——做题、拍照传错题。所有规划、分类、组卷、复习调度，全部由AI后台完成。孩子打开小程序就是"今天该做什么"，做完提交；遇到错题拍个照传上来，剩下的不用管。家长在思源笔记里看全貌。

---

## 01 核心定位

| 维度 | 说明 |
|------|------|
| 孩子操作 | 2步：做题 + 拍照传错题 |
| 孩子选择 | 0选择：不用选题、不用分类、不用规划 |
| 目标用户 | 初中生/高中生（河南考情），午托部孩子也可用 |
| 产品形态 | 微信小程序（孩子端）+ 思源笔记+Git（家长端/知识管理） |
| 成长型 | 越用越精准，错题数据积累后AI出卷越来越贴合薄弱点 |

### 孩子端 vs 后台/家长端

**孩子端（微信小程序）——极简操作，不浪费精力**
- 打开 → 看到今日任务
- 做题 → 提交 → 出分
- 遇到错题 → 拍照上传
- 完事，关掉就走

**后台 + 家长端（思源笔记）——AI干重活，家长看全貌**
- AI自动规划每日任务
- 拍照 → OCR → 知识点分类
- 错题库自动更新掌握度
- 按错题组卷、安排复习
- 家长在思源笔记看图谱和报告

> **设计铁律**：孩子不需要理解任何知识点分类、复习计划、学习路径——这些全在后台。孩子只感知到"今天要做这几题"和"拍一下就交了"。任何需要孩子做选择、做分类、做规划的界面，都是设计失败。

## 02 整体架构：三层分离

### 第一层：孩子端 — 微信小程序
两个页面：「今日任务」+「传错题」。不做复杂导航，不做模块选择。孩子打开就做，做完就走。

### 第二层：AI后台 — 云端服务 + 大模型API
每日凌晨生成任务清单 → 孩子提交后自动批改 → 错题OCR+知识点分类 → 更新掌握度模型 → 每周自动组卷。孩子完全感知不到这层。

### 第三层：家长端 — 思源笔记 + Git
知识图谱（知识点掌握度可视化）、错题原始记录、艾宾浩斯复习日历、每周/每月学习报告。Git每天自动commit，可回溯。

### 数据流向
```
AI后台（凌晨生成今日任务）
  → 推到小程序
  → 孩子做题提交
  → AI自动批改，更新掌握度
  → 孩子拍照传错题
  → AI做OCR+知识点分类，入错题库
  → 同步到思源笔记（家长看图谱和报告）
```

## 03 孩子的一天：完整流程

| 时间 | 动作 | 说明 |
|------|------|------|
| 早上/放学后 | 打开小程序，看到今日任务 | AI昨晚根据掌握度+艾宾浩斯到期项排好了。一般3-5个小任务，总时长20-30分钟 |
| 做任务 | 逐个做题，做完自动出分 | 选择题直接选；填空题打字；主观题打字后AI按得分点评分。做错的题不用孩子分析，后台自动记录 |
| 遇到错题 | 拍个照，上传，完事 | 不管是作业卷子上的错、考试的错、还是练习册的错，打开小程序点「传错题」，拍照/选图，点上传。不需要写知识点、不需要选分类 |
| 每周 | 收到一套"周测卷" | AI根据这周错过的知识点自动组了一套卷，推到小程序。孩子像做平时作业一样做完，提交，出分 |
| 每月 | 家长收到学习报告 | 思源笔记里自动生成月度报告：哪些知识点进步了、哪些还薄弱、下月重点补什么。孩子无感 |

> **关键体验原则**：孩子打开小程序应该只看到"今天做什么"，而不是"选古诗/选古文/选阅读"。所有内容选择由AI根据他的学习进度决定。任务量严格控制在20-30分钟，不能变成负担。

## 04 小程序界面设计（极简）

### 只有两个Tab

**Tab 1：今日任务**
进入即看到今日待做清单。每个任务一行：图标+题型+内容概要+预计用时。点进去直接做题，做完自动回到列表，该项打勾。

**Tab 2：传错题**
一个大的拍照按钮。拍了照、选了图、点上传，完事。AI后台处理，不需要孩子做任何标注。

### 今日任务页面示意

```
今日任务
─────────────────────
[古诗词背诵] 《茅屋为秋风所破歌》
  预计5分钟 · 跟读+挖空

[古文翻译] 《岳阳楼记》逐句翻译2句
  预计8分钟

[阅读理解] 记叙文片段练习
  预计10分钟 · 2道题

[作文素材] 今日金句积累
  预计2分钟
─────────────────────
📷 遇到错题？点这里拍一张
```

### 不做什么（克制清单）
- 不做「模块入口」（孩子不需要知道这是古诗词模块还是古文模块）
- 不做「题库浏览」（不让孩子自己选题）
- 不做「排行榜/社交」（午托部孩子不需要攀比）
- 不做「积分商城」（学习本身不该靠游戏化贿赂，保持任务简洁）
- 不做「家长端功能」在小程序里（家长去思源笔记看）

## 05 AI学习规划引擎（孩子看不到的那层）

### 每日任务怎么生成

每天凌晨，AI后台跑一遍规划算法，输出今日任务清单：

1. **复习项**：从错题库和已学内容中，按艾宾浩斯到期日筛选该复习的知识点，出对应的题
2. **新学项**：根据当前学习进度（教材章节、考纲进度），推进1-2个新知识点，出入门题
3. **薄弱项**：近期连续做错的知识点，加一道变式题再练
4. **平衡**：控制总时长20-30分钟，四个模块轮换，不连续两天全是古诗文

### 掌握度模型

每个知识点维护一个0-1的掌握度分数：

| 操作 | 掌握度变化 |
|------|-----------|
| 第一次做对 | +0.3 |
| 做错 | -0.3（入错题库） |
| 复习做对 | +0.15（间隔越长加越多） |
| 一周没碰 | 自然衰减 -0.05 |
| 掌握度 ≥ 0.8 | 移出高频复习，只在周测/月测中抽查 |

> **知识点体系（初始版）**：按河南考纲建立树状知识图谱——古诗词（按篇目×考点：默写/情感/手法）、古文（按实词×虚词×通假字×翻译）、阅读（按文体×题型）、作文（按主题×结构×素材）。初始知识树手动搭好，后续根据错题自动补充分支。

## 06 错题自动管理：拍照→识别→分类→归档

### 拍照上传后的AI处理流水线

```
拍照
  → OCR识别（文字提取，识别题干和孩子答案）
  → AI判型（LLM判断：哪个模块、哪个知识点、什么题型）
  → 更新掌握度（该知识点掌握度下降，入复习队列）
  → 存原始图（图片+文字+分类标签存到思源笔记对应笔记）
```

### 关键设计决策

- **孩子不需要选分类**：AI判断不了时（低置信度），不打断孩子，而是打个「待确认」标签，攒到周末让家长在思源笔记里批量确认
- **原图必须保留**：OCR识别的文字存文本，但原始拍照图也存着，方便回看卷面
- **不追求100%准确**：分类错了没关系——AI出卷时这个知识点如果标错了，孩子做了不对的题，下次AI会根据反馈修正。系统是成长型的，容错率要高
- **午托部批量场景**：如果多个孩子用，每个孩子有独立的错题库，AI规划按人独立运行。小程序里用微信昵称或学号区分

> **技术实现**：OCR可用微信小程序自带的OCR能力或腾讯云OCR；知识点分类用DeepSeek/Qwen大模型，给它一张OCR文本+知识点树，让它输出最匹配的节点ID。初期分类准确度80%就够用，剩下20%由家长在思源笔记里微调。

## 07 AI智能组卷：从错题到新试卷

### 两种出卷模式

**周测卷（每周自动）**
从本周错题涉及的知识点中，每个薄弱知识点出1-2道变式题（不是原题重复），凑成一套小卷。难度匹配孩子当前水平。周日推送到小程序，周一做完出分。

**专题卷（按需）**
如果某知识点连续错3次以上，AI临时加一套专项卷集中突破。比如「古诗鉴赏手法判断」连续错，就出5道同类型题集中练。

### 变式题怎么生成

孩子错过的题，AI不是让他再做一遍原题（没意义），而是生成**同考点不同文本**的新题：

- 错过「《XX》中『X』字好在哪里」→ AI找另一首同手法的诗，出同结构的赏析题
- 错过「下列加点词解释正确的是」→ 从通假字库找另一个同类型通假字出题
- 错过阅读「段落作用题」→ AI找另一篇同文体文本，出同题型

这就是为什么需要开源题库打底——chinese-poetry 5万首诗、通假字库1万+条、平行语料，给AI提供了足够多的「素材池」来生成变式题。

### 周测卷模板

| 板块 | 题量 | 说明 |
|------|------|------|
| 古诗文默写/背诵 | 3-5题 | 本周该复习的名句 |
| 古文实词/通假字 | 2-3题 | 本周错过的字词 |
| 古诗/古文赏析 | 1-2题 | 变式题，同考点换文本 |
| 阅读理解片段 | 1篇+2题 | 本周薄弱题型 |
| 作文小练笔 | 1题 | 不一定每周都有，两周一次片段训练 |

## 08 思源笔记：知识图谱与错题可视化

### 为什么用思源笔记+Git

- **双向链接**：知识点之间的关联可以用`[[双向链接]]`表示，形成知识网络而不是文件夹
- **Git同步**：所有笔记纳入Git版本管理，每次AI更新都有commit记录，可回溯、可回滚
- **块级引用**：一道错题、一个知识点、一篇阅读，都可以独立成块，互相引用
- **数据主权**：数据在自己手里，不依赖任何SaaS服务，将来想导出随时导出

### 知识图谱示意

红点=薄弱 · 黄点=需巩固 · 绿点=已掌握

```
[红] 古诗词·《茅屋》情感理解    [黄] 古文·通假字「通→通行」
[绿] 阅读·段落作用题            [红] 作文·开头不会写
[黄] 古文·「以」字用法          [绿] 古诗·默写
```

### 思源笔记目录设计

| 笔记/文件夹 | 内容 |
|------------|------|
| 学习仪表盘 | 主入口，展示当前知识图谱全貌、本周完成率、下周计划 |
| 错题库 | 按知识点分文件夹，每条错题：原图+OCR文字+错误时间+复习状态 |
| 知识点库 | 每个知识点一篇笔记：定义、答题模板、关联题目、掌握度 |
| 艾宾浩斯日历 | 每天该复习什么，AI每天自动更新 |
| 周/月报告 | AI生成的学习分析，趋势图、薄弱点、下月建议 |
| 原始题库备份 | 所有出过的题+答案+孩子作答记录，Git版本管理 |

> **自动化方案**：AI后台每天跑完后，自动通过思源笔记的API（或直接写markdown文件到Git仓库）把当天的错题、掌握度变化、复习安排写入对应笔记。不需要人工整理。家长打开思源笔记就是最新状态。

## 09 学习科学设计：为什么这样规划是科学的

### 艾宾浩斯间隔重复
每个知识点的复习时间按学后第1天、第3天、第7天、第16天、第35天、第90天安排。AI自动计算每个知识点的下次复习日期，到期自动出现在今日任务里。孩子不需要记「今天该复习什么」。

### 间隔提取（Retrieval Practice）
不是「再看一遍笔记」，而是「做题考自己」。每次复习都是用题目提取记忆，而不是重新阅读。这是认知科学验证过最有效的记忆方式。

### 交错练习（Interleaving）
今日任务里混合不同题型（古诗+古文+阅读），而不是连续做30分钟同一种题。虽然当下感觉更难，但长期记忆效果和迁移能力显著提升。

### 生成效应（Generation Effect）
错题不是看正确答案就完了，而是让孩子在周测卷里**重新做同类型的新题**。自己生成答案比被动阅读的记忆强度高得多。

### 难度适中（最近发展区）
AI控制题目难度：太简单的（已经掌握的）不浪费时间；太难的（超出当前水平的）不打击信心。大部分题目落在「跳一跳够得着」的区间——做过之后有提升感。

## 10 迭代路线图

| 阶段 | 时间 | 内容 |
|------|------|------|
| 最小闭环 | 第1-2月 | **手动版跑通**：不写代码。用思源笔记手动建错题库，AI（DeepSeek）手动出题，打印给孩子做。验证学习节奏、题目难度、错题分类思路 |
| 小程序MVP | 第3-4月 | 微信小程序上线：今日任务列表、做题界面、拍照上传。后台用脚本+DeepSeek API自动出题和分类。思源笔记Git同步跑起来 |
| 自动化 | 第5-6月 | AI自动组卷、掌握度打分、艾宾浩斯调度全自动。家长只需在思源笔记看报告，不用手动干预 |
| 午托部扩展 | 第7-9月 | 多学生支持，每个孩子独立错题库和学习进度。午托部场景下老师/家长看全班汇总 |
| 持续迭代 | 长期 | 内容自生长，题目越出越多、AI越用越准。寒暑假加套卷模式，考前加冲刺模式 |

> **第一个月不要写代码**：先用最笨的方法手动跑一遍——每天让DeepSeek出5道题，打印或发微信给孩子做，孩子拍错题发过来，你手动分类记到思源笔记里。跑两周就知道：这个题量对不对、孩子扛不扛得住、哪些分类AI判不准。验证完再写小程序，少走弯路。
