# ADR-0001 · 领域隔离：共享内核 + 学科插件

- 状态：已接受
- 日期：2026-09-22

## 背景

产品需要同时支持两个领域：初中语文（孩子用）和人文社科（自用）。两者题型、输入方式、批改方式、知识图谱都不同，但复习的间隔调度逻辑相同。

## 决策

把系统切成三层：

1. **共享内核**：统一数据模型、FSRS-6 间隔调度、进度与图谱渲染。与学科无关。
2. **领域插件**：语文、人文社科各自一个插件，通过四个接口（题目模板、作答器、批改器、图谱构建器）接入内核。
3. **基础设施**：ASR、OCR、LLM、思源导出等外部服务，领域插件和内核都可以调用。

## 约束（红线）

- 领域插件之间不互相 import。
- 共享内核代码里不出现「语文」「古诗」「概念」等学科词。
- 新增领域只写插件，不改动物理内核。
- 共享内核任何改动先过契约测试。

## 后果

- 正面：可以安全地「先做一块」，先跑通人文社科，再加语文；未来加英语 / 历史同样只写插件。
- 代价：多一层抽象；阶段 A 必须克制，只实现最小接口，避免过早设计。
