# 语知慧（yuzhihui）

面向个人自用的间隔重复学习助手。一个微信小程序，内置两个学习领域——**初中语文**（孩子用）与**人文社科**（自用）——共用同一套复习引擎，学科内容彼此隔离。

## 一句话

选择题在屏幕点选，主观题用语音 / 打字 / 答题卡拍照输入，AI 与参考答案核对批改，FSRS 排期复习，知识图谱沉淀到思源 + Git。

### 核心设计原则

1. **领域隔离**：语文域和人文社科域通过四个标准接口接入内核，互不污染
2. **共享内核**：FSRS 调度、数据模型、进度统计、图谱渲染只写一遍
3. **防浆糊机制**：ADR 记录架构决策、接口契约锁定边界、提交前自动检查

## 四个标准接口（领域插件契约）

每个学习领域必须实现以下四个接口，详见 `docs/contracts/README.md`：

| 接口 | 职责 |
|------|------|
| `TemplateProvider` | 题目模板：定义该领域有哪些题型、题面如何渲染 |
| `AnswerCollector` | 作答器：收集用户输入（点选/语音/打字/拍照），归一化为文本 |
| `Grader` | 批改器：将用户作答与参考答案比对，输出对错/得分/错因 |
| `GraphBuilder` | 图谱构建器：从题目和作答记录中提取知识点，构建知识图谱 |

## 路线图

- [ ] **阶段 A**：人文社科 MVP（选择题 + 打字主观题 + FSRS 复习）
- [ ] **阶段 B**：语文域接入（古诗词、文言文、阅读理解）
- [ ] **阶段 C**：答题卡拍照输入（OCR + 客观题识别）
- [ ] **阶段 D**：开放题精细批改（LLM 多维度评分 + 错因分析）
- [ ] **阶段 E**：知识图谱可视化 + 思源笔记同步

## 技术栈

- 前端：微信小程序（原生 / Taro）
- 后端：微信云开发（云函数 + 云数据库）
- 调度算法：FSRS-6（Free Spaced Repetition Scheduler）
- AI 服务：国内可访问的 LLM API（批改 + 分镜）
- 知识管理：思源笔记 + Git 版本控制
