# 语知慧 · yuzhihui

面向个人自用的间隔重复学习助手。一个微信小程序，内置两个学习领域——**初中语文**（给孩子用）与**人文社科**（自用）——两者共用同一套复习引擎，学科内容彼此隔离。

## 一句话

选择题在屏幕点选，主观题用语音 / 打字 / 答题卡拍照输入，AI 与参考答案核对批改，FSRS 排期复习，知识图谱沉淀到思源 + Git。

## 为什么这样组织

- 复习逻辑（哪种遗忘曲线、怎么排下次复习时间）是学科无关的，收进**共享内核**。
- 题库来源、题型、输入方式、图谱结构是学科特有的，压进各自的**领域插件**。
- 两个学科插件之间不互相依赖，共享内核代码里不出现任何学科名。

详见 [`docs/`](./docs/)。

## 核心概念

| 层 | 职责 | 内容 |
| --- | --- | --- |
| 共享内核 | 与学科无关的通用能力 | 统一数据模型、FSRS-6 调度、进度与图谱渲染 |
| 领域插件 | 每个学科自己的东西 | 题库、题型、作答器、批改器、图谱构建器 |
| 基础设施 | 外部服务 | ASR 语音转写、OCR、LLM 批改、思源导出 |

领域插件通过四个接口接入内核，定义见 [`docs/contracts/`](./docs/contracts/)。

## 路线图

- **阶段 A · 人文社科 MVP**：共享内核 + 人文社科插件（选择 + 概念卡），只实现「点选作答 + 选择批改」两个最小接口，自用跑通闭环。
- **阶段 B · 语文接入**：新增语文插件，先做选择题 + 语音 / 打字输入，不改内核一行代码。
- **阶段 C · 答题卡输入**：制式 A4 答题卡，孩子每 3 天做一张，二维码按题归档。
- **阶段 D · 开放题精细批改**：作文 / 阅读按 rubric 打分，远程抽查低置信度结果。
